# Native Henry Terra review/attach lane

After native generation, fetch `origin/main`, create an isolated worktree, and verify/link existing ignored private stores. Use no generation model. For at most one assembled reading, run `npm run mhc:native:review:prepare -- --work-item <work-item>`, directly compare every condensation with every cited atom in ignored staging, and create a schema-valid approved all-assertions-true schedule review only after that comparison. Create `review-approval.json` under the same staging directory, binding the exact handoff, review-candidate, and approved-review SHA-256 values. Apply only with `npm run mhc:native:review:apply -- --work-item <work-item> --review <approved-staged-review>`. Run `mhc:sync-latest`, metadata/content validation, and authorized manifest-last Drive publication only after the matching deterministic transaction directory contains its `committed.json` marker. Never let generation attach or publish. Safe-report failures without private prose, atoms, IDs, credentials, or secrets; retain fallback and manifest on any failure.
