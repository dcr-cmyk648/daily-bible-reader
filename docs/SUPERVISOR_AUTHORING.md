# Bounded supervisor authoring

Stages C and D implement the October 10 accepted supervisor work order. C permits
one distinct reading per 90-minute wake; D permits at most three, with five minutes
reserved for checkpointing. Daily and review automations remain ACTIVE. D alone
replaces the two legacy Henry author schedules after its acceptance gates pass.
Installation verifies committed closure bytes, offline ChatGPT login/version/tool
isolation, and the exact installed native source/manifest/config/launcher hashes
before replacing the supervisor pointer. It never performs a paid API call or
availability/model probe.

connector and receipt execution. Preserve the existing daily/review schedules,
project and ACTIVE status; the manager applies this model change after genuine C
acceptance. They never author, review prose, invent approval/health or decide a
retry. Uncertainty and denial remain visible. There is no separate archive flag.
Archive only their own run when the terminal status result has `kind:status`,
`outcome:complete`, `runComplete:true`, `workOutcome:complete`, null `code` and
`workCode`, and both `heartbeatDelivered:true` and `readerVisible:true`; a subsequent
installed `status` must retain the accepted source/stage and report
`lastOutcome:healthy_noop` with null `lastErrorCode`. These results follow durable
authenticated health/readback. Any missing signal, retained debt or blocker leaves
the chat open. Substantive child models remain unchanged below.

Consultation requires actual successful completed page access. Lossy CLI snippets
are discovery evidence only. In `bounded_https` mode code retrieves a completed

Every dispatch reserves its durable budget before execution. An uncertain dispatch
is parked without replay. Accepted raw output and admission hashes are checked on
reuse. One malformed output may receive a repair bound to its exact failed bytes;
one substantive daily changes request may receive a revised study and fresh review.
Author kind budgets never reset when an input or wake changes. Each exact native
review basis has two transport attempts; reading-wide capability/uncertainty
blocks persist across bases. Only validated native changes create a new basis. Native
Henry editorial repair also retains its one-packet repair limit. Review thread IDs
must differ from all actual author and repair threads. Machine validation alone
never approves prose.

validator before execution acceptance. An old envelope-only accepted result that
fails that validator can be reclassified only against the same unapplied native
editorial basis, exact original candidate and saved raw output. A hash-bound native
admission rejection is appended beside the original acceptance. Ordinal one stays
spent; the sole second transport attempt receives those exact failed bytes and
validator findings. It remains one native applied repair followed by fresh source
review. Changed proof/basis, uncertain dispatch, provider blocks and an invalid
second candidate cannot create another execution or reset native submissions.

Henry review action admission checks the exact source/native basis and repair
history before accepting a response or writing a native decision. The prompt lists
eligible and already repaired packets. A changes request cannot reuse a packet's
native repair; approved prose corrections must name unique existing verses, pass
the unchanged native schema/copy/reporting checks and satisfy every substantive

resolve its findings. An old envelope-only accepted ineligible action retains its
raw output and historical acceptance, with an appended hash-bound rejection.
Only its original remaining second transport attempt may correct that exact
response using the native diagnostic and same source/job head. No new review job,
author submission or native packet repair is granted. Changed source/head/proof,
uncertainty, capability blocks and an unsuccessful second response stay blocked.

Before dispatching Henry review, deterministic triage checks every compiled verse
with the pinned native source-reporting and source-copy gates. Complete findings
